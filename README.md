# BookSphere-Retail-Book-Sales-Business-Intelligence-Dashboard
An end-to-end data analytics project using Excel, SQL, and Power BI to analyze book sales, customers, products, revenue, and business performance.

The project explores sales performance, customer behavior, product trends, revenue, and other key business metrics through data cleaning, SQL analysis, and interactive Power BI dashboards.

### Tech Stack: Excel • SQL • Power BI

## Key Components:

• Data cleaning and preparation using Excel

• Data querying and analysis using SQL

• KPI and business-metric development

• Interactive Power BI dashboard

• Sales and revenue analysis

• Customer and product performance analysis

• Business insights and visualization
